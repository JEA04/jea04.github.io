This Page contains ideas that just come to mind. Whether they are projects that solve a problem or projects that would allow me to learn something new

- **Cubii:** A cube shaped Air Quality Monitoring Station.
- **Bluetooth IR Transmitter** A nRF54 PCB that allows control of my Lamp using BLE instead of the IR Remote I seem to always misplace.
- **Network Firmware Loader** which allows me to learn more about Ethernet, OTA and Bootloaders
- **Salae Logic Analyzer** so I can finally measure my FDCAN signals.
- **7-Port USB 2.0 Hub** that may work better than my current USB-HUB
- **Small Desktop Smart Home Display** using an STM32H7 Controller with a Touch Display
	- Use [grvl](https://github.com/antmicro/grvl) as graphics library
	- Might use this Display [Waveshare - 4-inch IPS 720x720px](https://www.waveshare.com/product/displays/lcd-oled/lcd-oled-2/lf40-720720-ark.htm)
- **LED Cube** similar to the one from [Greg Davill - Mini LED Cube](https://gregdavill.com/posts/mini-led-cube/) but the Cube is powered and controlled over Single Pair Ethernet (SPE).
- **Single Pair Ethernet Switch**: Switch providing a normal Ethernet connection together with multiple 100BASE-T1 and atleast one 10Base-T1S Interface
- A **Watch** using the **Alphanumeric Display** from Broadcom. 
	- Using a nRF54 or an Ambiq Processors
- Xilinx FPGA mapped connected to a STM32H7 using FMC
- A **10Base-T1S Node** using a STM32C5 and a LAN8650
- A **Single Pair Ethernet (SPE)** Switch
